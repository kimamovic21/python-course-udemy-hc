# Mini Story 1: Is the Kettle Ready?

**Start here:** This is the first mini project in `03_conditionals`, implemented in [mini_story_1.py](mini_story_1.py). Follow the [learning order](README.md#learning-order) rather than the order in which files appear in your editor.

You are preparing chai. Before making it, you need to check whether the kettle has boiled. Use a boolean variable and an `if` statement to decide whether to display a message.

## Tasks

1. Create `kettle_boiled` and assign it `True`.
2. Use an `if` statement to check `kettle_boiled`.
3. When the condition is true, print exactly:

   ```text
   Kettle Done! time to make Chai
   ```

## Try another value

Change `kettle_boiled` to `False` and run the program again. The message should no longer appear because the condition is false.

Read the [Python example](mini_story_1.py) and the [section README](README.md) for the implementation and explanation.
